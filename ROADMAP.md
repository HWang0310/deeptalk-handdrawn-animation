# Roadmap

## V1 — deterministic grammar prototype

- SVG scene schema, timed element reveal, Chinese text, stroke/fill ordering.
- Seven local benchmark fixtures and rendered MP4 evidence.
- Machine QA for geometry, timing, clipping-risk, text, density, and final-frame coverage.

## V1.1 — controlled visual refinement

- Hand-drawn stroke variation constrained by deterministic seed.
- Better icon/illustration primitives and composition templates.
- Human aesthetic scorecards collected on rendered evidence.

## V2 candidates — evaluate only after V1 evidence

- Optional hand-overlay experiment, isolated from the core renderer.
- Remotion only if benchmark timelines prove SVG/FFmpeg orchestration is insufficient.
- Reviewed still-image background adapters; never delegate Chinese factual text to image generation.
