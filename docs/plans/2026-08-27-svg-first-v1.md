# SVG-first Hand-drawn Animation V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local deterministic SVG-first hand-drawn animation prototype with seven benchmark assets and documented QA.

**Architecture:** Explicit JSON fixtures validate into a scene model. SVG compilation renders a deterministic scene at each timestamp; Resvg rasterizes PNG frames and FFmpeg encodes local MP4 evidence. QA evaluates declared geometry and timeline facts while human review remains manual.

**Tech Stack:** Node.js ESM, Node test runner, `@resvg/resvg-js`, FFmpeg.

**Spec:** `docs/superpowers/specs/2026-08-27-svg-first-v1-design.md`

## Global Constraints

- Use only local input and no API keys.
- Render 1920×1080 16:9 assets for 3–10 seconds at 12 FPS preview rate.
- Keep media ignored under `output/`.
- Do not modify DeepTalk Core or create an integration contract.

### Task 1: Scene schema and validation

**Files:** Create `test/schema.test.js`, `src/schema.js`, `fixtures/benchmarks.js`.

**Interfaces:** `validateScene(scene) -> scene`; `validateBenchmarks(benchmarks) -> benchmarks`.

- [ ] Write tests that reject a 2-second scene and a duplicate element ID; run `npm test -- test/schema.test.js` and confirm failure because the module does not exist.
- [ ] Implement duration, canvas, element-ID, time-window, primitive, and text validation; rerun the test until it passes.
- [ ] Define the seven named scene fixtures using only original primitives; add a coverage test that requires all benchmark IDs.
- [ ] Commit schema and fixture behavior.

### Task 2: Deterministic SVG compiler

**Files:** Create `test/svg.test.js`, `src/svg.js`.

**Interfaces:** `compileSvg(scene, timeMs) -> string`; `revealProgress(element, timeMs) -> {stroke, fill}`.

- [ ] Write tests asserting an unrevealed path has zero visible stroke, a mid-reveal path has a partial dash offset, Chinese label text is escaped, and final state includes fill; run and observe module-missing failure.
- [ ] Implement SVG XML escaping, style tokens, primitive serialization, dash reveal, fill timing, and final scene composition; rerun until green.
- [ ] Commit SVG compiler behavior.

### Task 3: Render pipeline
